# Remediation Plan (30-60-90 Days)

This action plan outlines the steps required to mitigate the risks identified during the NIST CSF 2.0 assessment of EcoMada.

## Immediate Actions (Next 30 Days) - Priority: High
*   **Risk R-003 (Score 25):** Enforce Multi-Factor Authentication (MFA) on all AWS and Shopify administrative accounts. Prohibit password sharing.
*   **Risk R-002 (Score 16):** Create a centralized asset inventory (Google Sheets/Excel) for all 25 devices. Enable remote wipe capabilities on all field tablets.
*   **Risk R-004 (Score 15):** Schedule and document one full restore test for the AWS database backups.

## Short-Term Actions (Next 60 Days) - Priority: Medium
*   **Risk R-001 (Score 12):** Draft and publish a formal "Cybersecurity Roles and Responsibilities" matrix (RACI) to clarify the roles between the internal IT specialist and the external web agency.
*   **Risk R-005 (Score 9):** Draft a basic Incident Response Plan (IRP) including emergency contacts, escalation steps, and customer communication templates.

## Long-Term Actions (Next 90 Days & Beyond) - Priority: Continuous Improvement
*   Conduct a tabletop exercise with management to test the Incident Response Plan.
*   Implement a basic security awareness training program for all 45 employees (focusing on phishing and password hygiene).
*   Review and update the risk register on a quarterly basis.
